# 📄 DocMind AI

## RAG-Based Document Analysis System

DocMind AI is an intelligent document analysis application that allows users to upload PDF documents and ask questions based on the document content.

## 🚀 Features

- 📄 Upload PDF documents
- 🔍 Extract text from PDF
- ✂️ Divide document into smaller chunks
- 🤖 Ask questions about the document
- 🧠 Retrieve relevant information using TF-IDF
- 📊 Calculate similarity between question and document chunks

## 🛠️ Technologies Used

- Python
- Streamlit
- PyPDF
- Scikit-learn
- TF-IDF
- Cosine Similarity

## ▶️ How to Run

1. Install the required libraries:

pip install streamlit pypdf scikit-learn

2. Run the application:

streamlit run app.py

3. Open the Streamlit URL in your browser.

## 🎯 Project Goal

The goal of DocMind AI is to make document analysis easier by allowing users to ask questions and retrieve relevant information directly from uploaded PDF documents.
